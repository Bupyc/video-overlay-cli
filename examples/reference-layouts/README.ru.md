# Примеры исходных шаблонов

[English](README.md) | Русский

Эти XML-шаблоны взяты из каталогов шаблонов и примеров проекта `gopro-dashboard-overlay`. Они показывают поддерживаемые компоненты в полных дашбордах, шаблонах для мотоцикла, дашбордах мощности, картах маршрутов и векторных индикаторах на основе Cairo.

## Список шаблонов

- `default-1920x1080.xml`, `default-2688x1512.xml`, `default-2704x1520.xml`, `default-3840x2160.xml` — основные дашборды в указанных размерах.
- `moto_1080.xml`, `moto_1080_2bars.xml`, `moto_1080_needle.xml` — шаблоны 1080p для мотоцикла и варианты индикатора оборотов.
- `moto_2160.xml`, `moto_2160_2bars.xml`, `moto_2160_needle.xml` — версии этих шаблонов 2160p.
- `power-1920x1080.xml` — дашборд велосипедной мощности и пульса.
- `example.xml` — вертикальный текст сверху вниз (`direction="ttb"`).
- `example-2.xml` — график, полосовой индикатор зон, маршрут и векторные индикаторы.
- `demo-circuit.xml`, `demo-gears.xml`, `demo-speed.xml`, `layout-cairo-2704x1520.xml` — отдельные примеры маршрута, передач, скорости и векторных индикаторов.

В основных шаблонах и шаблонах для мотоцикла используются карты с тайлами; для первого рендера новой области требуется подключение к сети. Подбирайте `--size` под размер шаблона, так как координаты виджетов абсолютные.

Статус поддержки и известные отличия перечислены в [таблице виджетов](../../docs/widget-matrix.ru.md) ([English](../../docs/widget-matrix.md)).
