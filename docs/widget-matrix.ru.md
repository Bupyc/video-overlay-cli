# Поддержка XML-виджетов

[English](widget-matrix.md) | Русский

Каталог основан на исходных Python-реализациях из `gopro_overlay/layout_xml.py` и `gopro_overlay/layout_xml_cairo.py`. Статус «Поддерживается» означает, что CLI на Go может отрисовать компонент из XML.

## Элементы XML

| Имя XML | Фабрика upstream | Статус | Описание |
|---|---|---|---|
| `composite` | контейнер | Поддерживается | Группирует дочерние виджеты и задаёт их положение. |
| `translate` | псевдоним `composite` | Поддерживается | Работает так же, как `composite`. |
| `frame` | контейнер | Поддерживается | Группа с рамкой, прозрачностью и настройками появления/исчезновения. |

## Фабрики XML-компонентов

| Тип компонента | Фабрика upstream | Статус | Описание |
|---|---|---|---|
| `asi` | `create_asi` | Поддерживается | Индикатор воздушной скорости. |
| `bar` | `create_bar` | Поддерживается | Полосовой индикатор числового значения. |
| `cairo_circuit_map` | `create_cairo_circuit_map` | Поддерживается | Векторный маршрут, маркер, поворот и разрывы маршрута для приватных зон. |
| `cairo_gauge_arc_annotated` | `create_cairo_gauge_arc_annotated` | Поддерживается | Векторный циферблат с дополнительной дугой метрики/значения. |
| `cairo_gauge_donut` | `create_cairo_gauge_donut` | Поддерживается | Кольцевой векторный индикатор с градиентной заливкой. |
| `cairo_gauge_marker` | `create_cairo_gauge_marker` | Поддерживается | Дуга векторного индикатора и маркер текущего значения. |
| `cairo_gauge_round_annotated` | `create_cairo_gauge_round_annotated` | Поддерживается | Векторный циферблат, подписи и стрелка. |
| `chart` | `create_chart` | Поддерживается | Окна графика по времени и дистанции. |
| `circuit_map` | `create_circuit_map` | Поддерживается | Записанный маршрут без картографических тайлов. |
| `compass` | `create_compass` | Поддерживается | Индикатор направления. |
| `compass_arrow` | `create_compass_arrow` | Поддерживается | Стрелка направления. |
| `datetime` | `create_datetime` | Поддерживается | Дата и время активности. |
| `gps_lock_icon` | `create_gps_lock_icon` | Поддерживается | Индикатор GPS-фиксации и иконка. |
| `icon` | `create_icon` | Поддерживается | Статическая иконка. |
| `journey_map` | `create_journey_map` | Поддерживается | Подгоняет маршрут к виджету и показывает текущую позицию; использует заданный источник тайлов. |
| `metric` | `create_metric` | Поддерживается | Форматированная метрика активности. |
| `metric_unit` | `create_metric_unit` | Поддерживается | Единицы измерения метрики. |
| `moving_journey_map` | `create_moving_journey_map` | Поддерживается | Маршрут в перемещающейся области просмотра; использует заданный источник тайлов. |
| `moving_map` | `create_moving_map` | Поддерживается | Карта с ориентацией по направлению движения и маркером маршрута; использует заданный источник тайлов. |
| `msi` | `create_msi` | Поддерживается | Индикатор оборотов двигателя. |
| `msi2` | `create_msi2` | Поддерживается | Второй вариант индикатора оборотов двигателя. |
| `text` | `create_text` | Поддерживается | Текст из содержимого XML; направления слева направо и сверху вниз. |
| `zone_bar` | `create_zone_bar` | Поддерживается | Индикатор зоны. |

`gradient_chart` — устаревший псевдоним: `create_gradient_chart` вызывает `create_chart`. Дефисы заменяются подчёркиваниями, поэтому, например, `cairo-gauge-donut` разрешается той же фабрикой. Обход контейнеров и рамок находится в `internal/render`, поэтому рендерер не зависит от пакета виджетов.

Все типы компонентов из включённых upstream-шаблонов поддерживаются Go-фабриками. Текст поддерживает исходные направления `ltr` и `ttb`. XML-валидатор проверяет тип компонента, но не отклоняет неподдерживаемые атрибуты.

## Виджеты без XML-фабрики

| Виджет | Статус | Описание |
|---|---|---|
| `SparkLine` | Только внутреннее использование | Создаётся из Go-кода внутри модуля; недоступен в XML и CLI. В upstream нет XML-фабрики. |
| `ComparativeEnergy` | Только внутреннее использование | Создаётся из Go-кода внутри модуля; недоступен в XML и CLI. В upstream нет XML-фабрики. |

Карты с тайлами по умолчанию используют OpenStreetMap, показывают атрибуцию и сохраняют данные в кэше ОС. Параметры `--tile-url`, `--tile-cache` и `--tile-attribution` выбирают совместимый источник тайлов. `--privacy LAT,LON,KM` скрывает карту в заданном радиусе. Неизвестный тип компонента приводит к явной ошибке до запуска FFmpeg.

Визуальный редактор шаблонов запланирован как отдельный проект [`video-overlay-ui/`](../../video-overlay-ui/), но пока не реализован. CLI читает и рендерит XML-шаблоны, но не редактирует их и не предоставляет предпросмотр.
